## 一句话结论

**抢不到通常不是「手速不够」，而是「请求根本没被服务端当成有效竞争」。**
先看错误码确定卡在哪一层，再动那一层 —— 盲加密度是白费。

## 快速判据（贴墙版）

```
看 250013  → 请求没被认     → 开火前 force-stop 冷启动刷新页面
看 250017  → 并发被限流     → 改成串行链（gapMs=0，等响应再发下一发）
看 300001  → 真进窗口没抢到 → 提高密度（串行链 ≈11.6 发/秒）
看 0       → 成功
```

---

## 三条不能忘的硬规则

1. **请求必须在页面里发** —— 脱离 WebView 没有原生签名，curl 必被拒。
2. **开火前必须冷启动** —— 否则请求被判 `250013`，等于没参赛。
3. **只能用串行链** —— 并发齐射会被限流 `250017`；串行链 11.6 发/秒且不限流。
